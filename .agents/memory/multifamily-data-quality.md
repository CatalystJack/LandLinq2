---
name: Multifamily data quality
description: The user's evidence standard for free data used in multifamily screening.
---

For multifamily screening, use free data that is reliable, recent, and real. Clearly distinguish observed records from estimates and proxies.

**Why:** the user wants free API data to be reliable, recent, and real.

**How to apply:** Prefer authoritative records with a verifiable publication or update date. Label survey estimates, modeled benchmarks, and lagged aggregates as such; do not present them as current property-level rents or occupancy.
