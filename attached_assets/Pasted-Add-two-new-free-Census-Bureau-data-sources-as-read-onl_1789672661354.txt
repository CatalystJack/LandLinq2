Add two new free Census Bureau data sources as read-only context columns on the analyst deal dashboard — no changes to YOC, comps, or any existing column's logic.

1. New service file server/censusDataService.ts (model it on the existing server/hellodataService.ts pattern — a plain service module the routes call into):

getFipsForCoordinates(lat, lng): calls the free, keyless Census Geocoder — https://geocoding.geo.census.gov/geocoder/geographies/coordinates?x=<lng>&y=<lat>&benchmark=Public_AR_Current&vintage=Current_Current&format=json — and pulls the state FIPS, county FIPS, and tract FIPS out of the response's Census Tracts block. Return null if the deal has no lat/lng yet, or if the call fails or returns no geographies (don't throw).
getAcsDataForTract(stateFips, countyFips, tractFips): calls the ACS 5-year API — https://api.census.gov/data/2023/acs/acs5?get=B01003_001E,B19013_001E,B25003_001E,B25003_002E,B25003_003E,B01002_001E&for=tract:<tract>&in=state:<state>+county:<county>&key=<CENSUS_API_KEY> — parses the response into { population, medianHouseholdIncome, ownerOccupiedUnits, renterOccupiedUnits, medianAge }. Compute renterOccupiedPct and ownerOccupiedPct from the occupied-unit counts. Also make a second call to the 2019 5-year vintage (.../2019/acs/acs5?...) for the same tract to get that period's population, and compute a rough populationGrowthPct from the two. If either call fails, still return whatever succeeded — never let a missing vintage null out the whole result.
getRecentBuildingPermits(stateFips, countyFips): the Building Permits Survey does NOT have a JSON API — it publishes one flat CSV per month at a fixed URL pattern (e.g. https://www2.census.gov/econ/bps/County/co<YYMM>y.txt, comma-separated). Fetch the current month's file, cache it in memory (or a small new table — your call, whichever is simpler in this codebase — but cache it, don't refetch per deal) for 24 hours, then look up the row matching this deal's state+county FIPS and sum the total residential unit columns to get "permits issued, trailing 12 months." If the file can't be fetched or parsed, or the county isn't found, return null — never throw, never block the rest of the deal from loading.

Wrap every one of the above in try/catch. A failure in any Census call must never break deal loading, never block deal creation/editing, and must just result in — shown in the UI for that deal.
