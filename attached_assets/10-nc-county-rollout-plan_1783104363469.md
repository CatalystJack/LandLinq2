# NC County Rollout Plan (statewide, sequenced)

The kit is explicit that one submarket at a time beats one whole metro on day
one, and a statewide mandate multiplies that advice by 100 counties. This file
sequences North Carolina into waves so "statewide" turns into a real Monday-
morning task list instead of a stalled ambition.

Run the four-stage engine (file 03) once per wave, per asset class. Don't open
Wave 2 until Wave 1 has cleared Stage 3 RESOLVE and you've reweighted the
signal library from whatever you learned (file 06's tuning guidance).

---

## Wave 1 — home metro, multifamily + land (weeks 1–3)

**Mecklenburg, Cabarrus, Union, Gaston**

This is Charlotte and its immediate growth ring. It's where Apex Residential's
brokerage license, broker network, and existing NC contact database already
live, so a resolved owner here converts to a call fastest. Mecklenburg has the
best data infrastructure in the state (Polaris 3G, direct GIS download), which
makes it the right place to debug your Stage 1 filters and your Stage 2 signal
weights before you carry them to counties with thinner data.

## Wave 2 — Triangle, multifamily + land (weeks 4–6)

**Wake, Durham, Chatham**

Wake's daily-refreshed bulk real estate file is the single best data pull in
the state — start Stage 1 here once Wave 1's filters are proven. Chatham is
already live in current work (Womble Farms, Pittsboro), so entity and owner
context you've already built there can seed Stage 3 RESOLVE.

## Wave 3 — Triad, multifamily only (weeks 7–8)

**Guilford, Forsyth**

Greensboro/Winston-Salem is a value-add multifamily market with less broker
competition than Charlotte or the Triangle. Land pass is optional here —
prioritize multifamily first and only add land if Wave 1–2 land results
justify the extra Stage 1 pull.

## Wave 4 — Western NC, land-weighted (weeks 9–10)

**Buncombe, Henderson**

Henderson County is already active (the Hendersonville feasibility work).
This wave leans land and small multifamily rather than 60+ unit assets — the
Asheville-adjacent market skews smaller and more land-driven.

## Wave 5 — Coastal and Southeast NC, opportunistic (weeks 11–12)

**New Hanover, Cumberland**

Run this wave only if Waves 1–4 are producing enough Priority-band owners to
keep outreach capacity full. If the call list is already saturated, this wave
can wait a quarter — the universe doesn't disappear, per file 09.

---

## Running the math on capacity

Before opening a new wave, check whether the prior wave's Priority-band count
(file 06: score 50+) exceeds what one person can call and letter in a week.
If Wave 1 alone produces 40+ Priority owners, that's the cadence in file 09
for weeks, and pulling Wave 2 data early just builds a backlog nobody works.
Sequence by capacity, not by ambition.

## What carries forward between waves

- **Signal weights.** Reweight file 04's point values from Wave 1's actual
  engaged owners before Wave 2 (file 06's tuning section). A signal that
  predicted real conversations in Charlotte should carry more weight in Wake
  too, until Wake's own data says otherwise.
- **Sender profile.** The sponsor-fit paragraph in the deal box
  (`02-deal-box-template-NC.md`) gets sharper as you close deals — add
  submarket-specific proof points as they happen ("we closed 3 deals in
  Mecklenburg this year" becomes true and citable after Wave 1).
- **Resolution shortcuts.** Any owner or entity resolved once in Stage 3 who
  turns up again in a later wave (a multi-county operator) doesn't need
  re-resolving — carry the evidence chain forward.

---

*All figures (weeks, owner counts) are planning assumptions to size the
work, not commitments — adjust to actual data-pull speed and your own outreach
capacity per file 09's maintenance-truth section.*
