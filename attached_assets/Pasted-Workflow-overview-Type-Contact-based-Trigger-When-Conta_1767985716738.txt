Workflow overview
Type: Contact-based
Trigger:

When Contact Tags is updated to include Jack LandLinq Broker
Actions (recommended full flow):

(Optional, but recommended) Set an “Assignment” field on the contact

Example property name (custom): LandLinq Assigned Broker
Value: the internal name/ID of the team member or routing logic you want LandLinq to understand.
Purpose: This makes it clear in HubSpot who owns the broker relationship and gives LandLinq a clear assignment input.
Send a webhook to LandLinq (https://landlinq.ai/api/webhooks/hubspot)

Method: POST
Content-Type: application/json
Payload (recommended fields):
{
  "email": "{{ contact.email }}",
  "firstName": "{{ contact.firstname }}",
  "lastName": "{{ contact.lastname }}",
  "contactId": "{{ contact.hs_object_id }}",
  "contactTags": "{{ contact.radio_select }}",
  "assignmentField": "{{ contact.<your_assignment_field> }}",
  "source": "hubspot",
  "event": "BROKER_TAGGED"
}
You’ll adapt {{ contact.<...> }} with HubSpot’s UI token picker.
(Optional) Internal notification to your team

Send an internal email or create a task:
“New LandLinq Broker tagged: {{ contact.fullname }} ({{ contact.email }}) has been sent to LandLinq.”
