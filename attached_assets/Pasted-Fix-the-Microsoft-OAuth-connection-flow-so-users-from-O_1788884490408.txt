The Azure App Registration has now been configured as multi-tenant (Multiple Entra

TASK 1 — Use 'organizations' instead of our specific tenant ID for the authorize URL
In server/routes.ts (~line 29519), the OAuth authorize URL currently uses our own 
tenantId directly:
  https://login.microsoftonline.com/${tenantId}/oauth2/v2.0/authorize
Change this to use 'organizations' instead of tenantId:
  https://login.microsoftonline.com/organizations/oauth2/v2.0/authorize
This matches the Azure app's new multi-tenant configuration and allows any real 
work/school Microsoft account from any company to sign in (personal accounts 
remain excluded, consistent with the "Multiple Entra ID tenants" setting chosen, 
not "+ Personal Microsoft accounts").
