first login: React error #300, confirmed directly from React's own 
documentation (react.dev/errors/300) to mean "Rendered fewer hooks than 
expected" — a component is calling a different number of hooks (useState, 
useEffect, useQuery, etc.) between renders, which happens when hooks are called 
conditionally, e.g. after an early return statement.

This started appearing after the recent isInitialized/auth-timing fix to 
client/src/App.tsx and client/src/pages/auth.tsx — very likely one of these 
changes introduced an early return or conditional branch that occurs before all 
of a component's hooks are declared, violating React's Rules of Hooks.

TASK 2 — Audit App.tsx and auth.tsx for conditional hook calls
Specifically check whether either file has any early return (e.g. based on

same order, on every single render — an early return is only safe if it happens 
AFTER all hooks for that component have already been called.
