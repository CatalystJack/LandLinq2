### Who it's for

## Built for developers, applications, and AI workflows

## Access the same Regrid parcel data through traditional REST endpoints or our MCP server using a single API token.

#### REST  API

Our core HTTP endpoints are designed for high-throughput enterprise applications, automated data pipelines, and high-speed transactional lookups. It features asynchronous batch endpoints capable of handling 100,000-point requests smoothly.

#### MCP  Server

A native, protocol-level interface that allows secure enterprise AI tools, private LLMs, and development environments (like Gemini, Claude, or Chat GPT) to query our data fields using plain English.

[Learn more](https://regrid.com/mcp)
