### api.openrouteservice.org is deprecated - please use api.heigit.org!

As [announced in this forum](https://ask.openrouteservice.org/t/deprecating-api-openrouteservice-org-in-favour-of-api-heigit-org/7912), as of April 28th, 2026, the URL `api.openrouteservice.org` is deprecated in favour of `api.heigit.org`. This is **only** a deprecation of the URL, **not** a deprecation of the services accessible via `api.openrouteservice.org` \- you will still be able to use all services as before, just with a different URL!

Dear users,

since April 28th, 2026, the URL `api.openrouteservice.org` has been **officially deprecated** in favour of `api.heigit.org`.

Details can be found in [this announcement](https://ask.openrouteservice.org/t/deprecating-api-openrouteservice-org-in-favour-of-api-heigit-org/7912).

We have noticed that since then, less than 5% of all API Requests are using the new API.

To give our users the possibility to gracefully migrate their applications, analyses and workflows, we have decided to not shut down `api.openrouteservice.org` directly, but rather reduce the quota of all API keys when using the deprecated API.

If you are using `api.openrouteservice.org`, starting today, August 27th, 2026, you will **only have 10% of the quota** listed [in our plans](https://account.heigit.org/info/plans). Using `api.heigit.org`, you of course have the full quota.

~~We will **shut down**`api.openrouteservice.org` on **September 28th, 2026**.~~

We [released our new web client](https://ask.openrouteservice.org/t/new-web-client-shutting-down-old-clients/8072) on **September 28th, 2026**.

We will **shut down**`api.openrouteservice.org` on **November 02nd - 06th, 2026**.

Best regards

the openrouteservice team
