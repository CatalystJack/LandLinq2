## Download Seamless Wetlands Data

[National Wetlands Inventory](https://www.fws.gov/node/255036) (NWI) data can be accessed in several ways depending on your needs. To display and query wetlands data in your software application please use our [Web Map Services](https://www.fws.gov/node/264587). This will ensure you have the latest data and reduce data management overhead. If you need to conduct [GIS analysis](https://www.fws.gov/program/national-wetlands-inventory/gis-tools-and-resources "GIS Analytical Tools and Other Resources") please reference the information below to download the data by watershed or by state. **For downloads larger than a state, please contact the Wetlands Team ( [wetlands\_team@fws.gov](mailto:wetlands_team@fws.gov)) to request a custom download.**

Please note that NWI data is continuously being improved and new data is added on a biannual basis. Those updates are reflected on the [Wetlands Mapper](https://www.fws.gov/node/264590) and in the data downloads in October and May of each year. To ensure that you have the most up to date information, please refer to the published date in the metadata, the location of new data on the [Projects Mapper](https://www.fws.gov/node/264590) and download new data regularly.

### Downloading Data

Data can be downloaded by HUC 8 Watershed Boundary or by State.  The data is downloaded as a [.zip](https://en.wikipedia.org/wiki/ZIP_file_format) file that contains the following layers:

1. Wetlands polygon data
2. Wetlands Project Metadata (includes image dates and project information)
3. Wetlands Historic Map Information\*
4. Riparian polygon data\*
5. Riparian Project Metadata (includes image dates and project information) \*
6. Watershed Boundary Dataset (WBD) HUC8 modified\*\*

\\* If available at the requested location.

\\*\\* Not included in State downloads.

Information about each of these layers can be found on our [Metadata](https://www.fws.gov/node/264592) page.

Detailed documentation of the Cowardin Classification system can be found on our [Wetland Code](https://www.fws.gov/node/264828) page. Here you can also download the [NWI Code Definitions Table](https://www.fws.gov/node/264828) that provides users with the full wetland or deepwater habitat description within their own mapping application.

Wetlands data viewed on the Wetlands Mapper can be downloaded by **HUC8 watershed** or by **State or U.S. Territory** in either file [Geodatabase](http://www.esri.com/software/arcgis/geodatabase/index.html) , [Shapefile](http://www.esri.com/library/whitepapers/pdfs/shapefile.pdf) (watersheds only) or [GeoPackage](https://proceedings.esri.com/library/userconf/proc17/tech-workshops/tw_2585-349.pdf) format. The Wetlands Mapper 'Get Data' button allows data to be downloaded by HUC8 watershed or by state. The State Downloads page allows data to be downloaded by state.

### Viewing Data

You can view the Geodatabase and Shapefiles by using ESRI's [ArcGIS Explorer](http://www.esri.com/software/arcgis/explorer/index.html) free software, among others. **Please note that ArcGIS version 10.\* is required for Geodatabase downloads**.

State and watershed data downloaded will be in an equal area [Albers projection](https://www.fws.gov/node/264848) with a **North American Datum (NAD) of 1983**.

**\*AutoCAD\* users**: In order to view NWI data you must first add the [Albers projection information](https://www.fws.gov/node/264848) into your AutoCAD library. Do this by using the MAPSCSCREATE command and click ‘c’ for coordinate system. Then input the Albers specific projection information.
